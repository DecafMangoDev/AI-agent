# General purpose agent

Консольный универсальный агент с OpenAI-compatible tool calling, SQLite-восстановлением, Plan Mode, единым бюджетом, задачами с зависимостями и журналом изменений с rollback. Обычный разговор не запускает инструменты workspace; они включаются для запросов о коде, файлах, командах и проекте.

## Запуск

```bash
python3 -m agent --workspace workspace
```

По умолчанию используется локальная Ollama-модель `qwen3:4b` через `http://localhost:11434/v1/`.
Запустите её командами `ollama pull qwen3:4b` и `ollama serve`, затем настройте `.env` по примеру `.env.example`.
Для другого OpenAI-compatible провайдера замените `OPENAI_BASE_URL` и `OPENAI_MODEL`.
Лимиты лежат в `agent.toml` и действуют на весь `run_id`, включая plan, approve, resume и retry.

```toml
[limits]
model = 20
tools = 40
effects = 15
result = 120000
```

Бюджет действует на весь `run_id` и хранится в SQLite. `model` считает запросы к модели, `tools` — отдельные вызовы инструментов, `effects` — потенциально изменяющие действия (`write_file`, `delete_file`, `bash`), а `result` — суммарный размер результатов инструментов в байтах. Перед запросом или вызовом runtime атомарно списывает нужную единицу и только затем выполняет действие. Для ответа модели с несколькими tool calls сначала проверяются и списываются все `tools` и `effects`; если остатка недостаточно, не запускается ни один вызов из пачки. В progress-логах показывается остаток всех четырёх счётчиков.

Доступные инструменты: `list_files`, `read_file`, `write_file`, `delete_file`, `bash`. Bash ограничен командами поиска, тестирования и `git status/diff`; пути не могут выйти из workspace.

## Чаты и восстановление

После каждого события CLI печатает прогресс в stderr. SQLite по умолчанию находится в `.agent/state.sqlite3`. Внутри сеанса:

```text
/new                           начать новый чат, сохранив текущий в SQLite
/chats                         список чатов с первым запросом
/resume [run_id]               показать и продолжить чат
/approve /reject               подтвердить или отклонить сохранённый план
/status  /budget  /tasks       состояние, расход и чеклист задач
/diff                          diff текущего run_id
/resolve <id> retry|fail|abort разрешить неизвестный вызов после сбоя
/rollback                      откатить изменения текущего run_id
/exit
```

Можно выбрать чат до запуска: `python3 -m agent --resume <run_id>`. Без идентификатора `--resume` продолжает самый свежий чат.

## Plan Mode и задачи

```bash
python3 -m agent --plan --workspace workspace
```

До подтверждения плана разрешены только чтение и просмотр. После approve шаги становятся задачами с зависимостями. После успешного инструмента агент показывает результат и спрашивает пользователя о его приемлемости; только подтверждение пользователя переводит задачу в `done`, а отказ возвращает её на доработку. Полное проектное обоснование находится в [DESIGN.md](DESIGN.md).
